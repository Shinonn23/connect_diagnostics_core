## Base Class & Imports (mandatory)

```python
from frappe.tests.utils import FrappeTestCase  # always — never bare unittest.TestCase
```

## Mock-Patch Pattern (unit tests)

```python
from unittest.mock import MagicMock, patch

class TestMyFunction(FrappeTestCase):
    def test_something(self):
        with patch("frappe.has_permission", return_value=True):
            result = my_function("Item")
        self.assertEqual(result, {"data": {}})
```

## Multi-Patch Helper with ExitStack

When a function needs 3+ patches, use `@contextmanager` + `ExitStack` to avoid deeply nested `with` blocks:

```python
from contextlib import ExitStack, contextmanager

class TestMyFunction(FrappeTestCase):
    @contextmanager
    def _patch_all(self, *, flag=True, rows=None):
        with ExitStack() as stack:
            stack.enter_context(patch("frappe.has_permission", return_value=flag))
            stack.enter_context(patch("frappe.get_all", return_value=rows or []))
            yield

    def test_happy_path(self):
        with self._patch_all(rows=[{"name": "X"}]):
            result = my_function("Item")
```

- `_patch_all` returning a plain `tuple` does NOT work as a context manager — must use `@contextmanager` + `ExitStack`

## Patching frappe.get_all with Side Effect (doctype-conditional)

```python
def _get_all_side_effect(doctype, **_kwargs):
    if doctype == "Alias Name":
        return alias_rows
    return source_rows

patch("frappe.get_all", side_effect=_get_all_side_effect)
```

## Test Naming Convention

- Method names: `test_<expected_behavior>` (e.g., `test_raises_permission_error_when_no_read_access`)
- Test documents: prefix with `_Test ` (e.g., `_Test Registration`)

## Running Tests

```bash
# Enable tests first (one-time per site)
bench --site dev.local set-config allow_tests true

# Run specific module
bench run-tests --app connect_diagnostics_core --module connect_diagnostics_core.api.connect_diagnostics_core.test_alias_name

# Run all app tests
bench run-tests --app connect_diagnostics_core
```

## Coverage Requirement

- Minimum: **one test per hook handler** + **one per whitelisted API method**
- Edge cases to cover: no permission, not configured/disabled, field validation failure, happy path, fallback behavior, empty records

## Dead Ends

- No `pytest` setup found — all tests use `bench run-tests` (Frappe's test runner wraps unittest)
- No test fixtures/factories utility — tests create mock objects inline with `MagicMock()`
- Boilerplate test files generated by Frappe (`test_alias_name.py`, `test_alias_supported_doctype.py`) are empty stubs — safe to overwrite with real tests
