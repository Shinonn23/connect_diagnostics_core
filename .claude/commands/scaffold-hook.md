Create a new Frappe API hook handler for a doctype. Ask the user for these details before generating:

1. **DocType name** (e.g., "Employee", "Product Registration")
2. **System** — `erpnext` or `frappe` (which system does this doctype belong to?)
3. **Hook types** — which hooks to implement (choose one or more):
    - `autoname` — Called while naming. Set `doc.name` to assign a custom name.
    - `before_insert` — Called before a document is inserted.
    - `validate` — Called before document is saved. Throw exception to prevent save.
    - `on_update` — Called after the document is inserted or updated in the database.
    - `on_submit` — Called after submission.
    - `on_cancel` — Called after cancellation.
    - `on_trash` — Called after document is deleted.

## Rules — follow these strictly

### File location

- Create at: `connect_diagnostics_core/api/<system>/<doctype_name>.py`
- `<doctype_name>` = lowercase, spaces replaced with underscores (e.g., `product_registration.py`)
- If the file already exists, append new hook functions to it — do NOT overwrite existing functions

### Function signature

All hook functions must follow this pattern:

```python
# Copyright (c) 2026, Siwat Sroisuwan and contributors
# For license information, please see license.txt

from __future__ import annotations

from typing import TYPE_CHECKING

import frappe
from frappe import _
from frappe.model.document import Document

if TYPE_CHECKING:
    from frappe.types import DF


def validate(doc: Document, method: str) -> None:
    if method != "validate":
        return
    # validation logic here


def autoname(doc: Document, method: str) -> None:
    # Set doc.name with custom naming logic
    doc.name = "generated-name"
```

### Register in hooks.py

Add the hook to `doc_events` in `connect_diagnostics_core/hooks.py`:

```python
doc_events = {
    # ... existing entries ...
    "DocType Name": {
        "validate": "connect_diagnostics_core.api.<system>.<doctype_name>.validate",
    },
}
```

- Do NOT remove or reorder existing entries
- Add new entry in alphabetical order by doctype name

### Generate test file

Create a test at `connect_diagnostics_core/tests/test_<doctype_name>.py`:

```python
# Copyright (c) 2026, Siwat Sroisuwan and contributors
# For license information, please see license.txt

from frappe.tests.utils import FrappeTestCase


class Test<DoTypeName>(FrappeTestCase):
    def test_validate_<scenario>(self):
        doc = frappe.get_doc({"doctype": "<DocType>"})
        with self.assertRaises(frappe.ValidationError):
            doc.insert()
```

- Include at minimum one test per hook type created
- Use descriptive test names: `test_validate_<scenario>`, `test_autoname_<scenario>`

- Modify any `.json` files (DocType definitions are auto-generated by Frappe)
- Create or modify `__init__.py` files
- Add dependencies or imports that don't exist in the project
- Overwrite existing functions in an existing API file
