### Added

#### `feat:` เพิ่ม JavaScript สำหรับ Doctype และ item selection API

**Commit:** `49f80cd` | `1550130` | **วันที่:** 18 พฤษภาคม 2026 | **ผู้แต่ง:** Shinonn23

เพิ่ม public JS scripts สำหรับ 6 doctype ใหม่ และ whitelist API สำหรับ item selection

**ไฟล์ JS ที่เพิ่มใหม่ทั้งหมด (`public/js/custom/`):**

| ไฟล์                          | หน้าที่                                                            |
| ----------------------------- | ------------------------------------------------------------------ |
| `delivery_note/doctype.js`    | filter item ตาม warehouse availability                             |
| `material_request/doctype.js` | filter item + validate schedule date (ห้ามเป็นอดีต / เกิน 180 วัน) |
| `purchase_order/doctype.js`   | filter item ตาม warehouse                                          |
| `quotation/doctype.js`        | filter item ตาม warehouse                                          |
| `sales_order/doctype.js`      | filter item ตาม warehouse                                          |
| `sales_order/list_view.js`    | list view script สำหรับ Sales Order                                |
| `stock_entry/doctype.js`      | filter item ตาม warehouse                                          |

ทุก script ใช้ `connect_diagnostics_core.api.erpnext.item.get_item_with_stock` สำหรับ query

**Python API ที่เพิ่มใหม่:**

- `api/erpnext/item.py` — whitelisted method `get_item_with_stock()` ค้นหา item พร้อมแสดง actual qty จาก Bin; รองรับ filter warehouse; ใช้ parameterized SQL
- `api/erpnext/supplier.py` — `CustomSupplier` class: autoname จาก `custom_dksh_supplier_code` / `custom_cd_supplier_code`; validate + auto-rename เมื่อ DKSH code เปลี่ยน
- `api/erpnext/employee.py` (เขียนใหม่) — `CustomEmployee` class แทนที่ฟังก์ชัน `autoname()` เดิม (ดูส่วน Refactored ด้านล่าง)

**hooks.py เปลี่ยนแปลง:**

```python
# เพิ่มใหม่
doctype_js = {
    "Delivery Note": "public/js/custom/delivery_note/doctype.js",
    "Material Request": "public/js/custom/material_request/doctype.js",
    "Purchase Order": "public/js/custom/purchase_order/doctype.js",
    "Quotation": "public/js/custom/quotation/doctype.js",
    "Sales Order": "public/js/custom/sales_order/doctype.js",
    "Stock Entry": "public/js/custom/stock_entry/doctype.js",
}
doctype_list_js = {"Sales Order": "public/js/custom/sales_order/list_view.js"}

override_doctype_class = {
    "Customer": "connect_diagnostics_core.api.erpnext.customer.CustomCustomer",
}

# doc_events เปลี่ยนจาก → ไปเป็น
# เดิม: Employee.validate, Employee.autoname, Employment Type.validate, Customer.autoname
# ใหม่: Customer.validate, Supplier.before_naming, Supplier.validate, Employee.before_naming

# override_whitelisted_methods ถูกลบออก
# เดิม: override rename_tool.upload → ปัจจุบัน: disabled (comment out)
```

### Added 7 พฤษภาคม 2026

#### `feat:` เพิ่ม DocType `Alias Name` และ `Alias Supported DocType` (แทนที่ Rename Tool V2)

**วันที่สร้าง DocType:** 7 พฤษภาคม 2026

สร้าง DocType ใหม่ 2 ตัวเพื่อแทนที่ระบบ Rename Tool V2 เดิม:

**`Alias Name`** — เก็บ mapping ระหว่าง primary record กับชื่อแสดงผลอื่น

| Field                   | Type           | หมายเหตุ       |
| ----------------------- | -------------- | -------------- |
| `documents`             | Link → DocType | ประเภท DocType |
| `primary_name`          | Dynamic Link   | record ต้นทาง  |
| `original_display_name` | —              | ชื่อ original  |
| `alias_name`            | —              | ชื่อ alias     |

**`Alias Supported DocType`** — กำหนดว่า DocType ใดรองรับ Alias

| Field               | Type           |
| ------------------- | -------------- |
| `reference_doctype` | Link → DocType |
| `alias_field`       | Select         |
| `is_enabled`        | —              |
| `descriptions`      | —              |

**API ใหม่:** `api/connect_diagnostics_core/alias_name.py`

- `get_supported_doctypes()` — @whitelist, คืนค่า DocTypes ที่ `is_enabled=1`
- ตรวจสิทธิ์ด้วย `frappe.has_permission("Alias Supported DocType", "read")`

**DocType เดิมที่ถูกแทนที่:**

- `connect_diagnostics_core/doctype/rename_tool_v2/` — ถูกลบออกทั้งหมด (js, py, test_py)
    - เดิมทำหน้าที่: Select DocType → เลือกไฟล์ → rename และ log ผล
    - `override_whitelisted_methods` ที่ override `rename_tool.upload` ก็ถูกลบออกพร้อมกัน

**DocType อื่นที่ถูกลบพร้อมกัน:**

- `connect_diagnostics_core/doctype/sub_department_assignment/` — ถูกลบทั้ง doctype (json, py, `__init__.py`) โดยไม่มี replacement
- `tests/test_employee_autoname_format.py` — ถูกลบ (tests ถูกรวมเข้า test suite หลักแล้ว)
