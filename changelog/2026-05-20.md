### Added

#### `feat(accounting):` เพิ่มโมดูล Connect Diagnostics Accounting พร้อม DocType `Accounting Department`

**วันที่:** 20 พฤษภาคม 2026 | **ผู้แต่ง:** Shinonn23

เพิ่มโมดูลใหม่ `connect_diagnostics_accounting` สำหรับงานบัญชี พร้อม DocType แบบ tree ที่ใช้สำหรับจัดกลุ่มฝ่าย/แผนกบัญชี และย้าย report `trial_balance_th` มาอยู่ในโมดูลนี้

**โครงสร้างโมดูลใหม่:**

| Path                                                                                              | คำอธิบาย                                                       |
| ------------------------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| `connect_diagnostics_accounting/doctype/accounting_department/`                                   | Tree DocType (NestedSet) ผูกกับ Company มี autoname, validation |
| `connect_diagnostics_accounting/doctype/accounting_department/accounting_department.js`           | Form script พร้อมปุ่ม convert group ↔ ledger                    |
| `connect_diagnostics_accounting/doctype/accounting_department/accounting_department_tree.js`      | Tree view script + dialog เพิ่ม child department               |
| `connect_diagnostics_accounting/doctype/accounting_department/accounting_department_dashboard.py` | Dashboard config                                             |
| `connect_diagnostics_accounting/doctype/accounting_department/test_accounting_department.py`      | Test cases สำหรับ doctype                                      |
| `connect_diagnostics_accounting/report/trial_balance_th/`                                         | ย้ายมาจาก `connect_diagnostics_core/report/trial_balance_th/` |

**ความสามารถของ `Accounting Department`:**

- ใช้ `frappe.utils.nestedset.NestedSet` เป็น base class สำหรับโครงสร้างต้นไม้
- `autoname` ใช้ `erpnext.accounts.utils.get_autoname_with_number` ผูกกับ Company
- Validate ป้องกัน parent ที่ไม่ใช่ group, ป้องกัน root มี parent
- `@frappe.whitelist` `convert_group_to_ledger()` / `convert_ledger_to_group()` พร้อม guard ตรวจสอบ child และ GL Entry
- รองรับ `disabled` flag สำหรับ soft-disable

#### `feat:` Auto-create root Accounting Department ตอนสร้าง/อัปเดต Company

**ไฟล์ใหม่:** `api/erpnext/company.py`

- Hook `on_update` ของ Company เรียก `create_default_accounting_department(doc, method)` เพื่อสร้าง root department อัตโนมัติเมื่อมี Company ใหม่
- เพิ่ม entry ใน `hooks.py` → `doc_events["Company"]["on_update"]`

#### `feat:` เพิ่ม Override class สำหรับ Supplier และ Employee (แทนที่ before_naming)

- เพิ่ม `override_doctype_class` ใน `hooks.py`:
  - `Supplier` → `CustomSupplier`
  - `Employee` → `CustomEmployee`
- ลบ `doc_events.Supplier.before_naming` และ `doc_events.Employee.before_naming` ที่ทำงานเดิม
- Logic autoname ทำใน class override โดยตรงเพื่อให้สอดคล้องกับ ERPNext pattern

#### `feat(stock):` เพิ่ม DocType `Product Group`

**ไฟล์ใหม่:** `connect_diagnostics_stock/doctype/product_group/`

- ใช้สำหรับจัดกลุ่ม product ภายใน module stock
- มี `.json`, `.py`, `.js`, `test_product_group.py`

#### `feat:` เพิ่มไฟล์ทดสอบ API สำหรับ Customer / Employee / Supplier

| ไฟล์                                  | จำนวนบรรทัด |
